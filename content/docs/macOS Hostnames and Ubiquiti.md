# macOS Hostnames and Ubiquiti

What do when a device shows with the hostname “Mac” in Ubiquiti - fix up MAC Addressing

Shout out to: https://www.reddit.com/r/UNIFI/comments/1lyb4sj/comment/n2swlyw/

tl;dr - set your macOS Private MAC Address setting to Off for the network. If it’s set to Fixed it sends a generic hostname (eg. iPhone.local, Mac.local) to the router.
